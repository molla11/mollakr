mollakr
=======
mollakr에 오신 것을 환영합니다!
----------------------------
이 레포지토리는 HTML 공부, 실습을 진행했었고 지금에는 각종 정보와 간단한 서비스가 들어 있습니다.
<br>현재 Github Pages 를 통해서 https://molla.kr 을 서비스 중입니다.

홈페이지의 소개 내용은 `content.md`에서 수정할 수 있습니다. 제목, 문단, 목록, 링크, 굵은 글씨, 구분선과 마크다운 강제 줄바꿈(줄 끝의 공백 두 칸)을 지원합니다. 제목에 `{#id}`를 붙이면 해당 섹션의 색상과 동작을 정하는 ID로 사용됩니다.
